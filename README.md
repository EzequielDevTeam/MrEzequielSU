# MrEzequielSU

Solucao de root via kernel, com nome e cara proprios.

**Creditos e licenca:** baseado no [APatch](https://github.com/bmax121/APatch) por **bmax121** (e KernelPatch/KernelSU relacionados). Licenca **GPL-3.0** — ver `LICENSE` do projeto original. Nenhum credito original foi removido do codigo.

## Build

Automatico via GitHub Actions (`Build MrEzequielSU`): baixa o fonte oficial, aplica o rebrand (`me.bmax.apatch` -> `com.mrezequiel.su`, nome visivel -> MrEzequielSU) e compila os APKs. Resultado em Artifacts.
